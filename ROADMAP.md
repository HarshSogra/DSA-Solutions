# 🗺️ DSA Learning Roadmap

A pattern-first roadmap for building strong DSA fundamentals and interview readiness.

## Phase 1 — Foundations

- [ ] Arrays
- [ ] Strings
- [ ] Hashing
- [ ] Sorting
- [ ] Basic Recursion

**Goal:** Build strong fundamentals and understand complexity analysis.

## Phase 2 — Core Patterns

- [ ] Two Pointers
- [ ] Sliding Window
- [ ] Prefix Sum
- [ ] Binary Search
- [ ] Fast & Slow Pointers

**Goal:** Learn to recognize reusable patterns instead of brute-forcing every problem.

## Phase 3 — Linear Data Structures

- [ ] Linked List
- [ ] Stack
- [ ] Queue
- [ ] Deque

**Goal:** Become comfortable with implementation, traversal, and common interview patterns.

## Phase 4 — Trees

- [ ] Binary Trees
- [ ] Tree Traversals
- [ ] BST
- [ ] Lowest Common Ancestor
- [ ] Tree Recursion

**Goal:** Become comfortable with recursive and iterative tree problems.

## Phase 5 — Advanced Data Structures

- [ ] Heap / Priority Queue
- [ ] Trie
- [ ] Union Find

## Phase 6 — Graphs

- [ ] BFS
- [ ] DFS
- [ ] Connected Components
- [ ] Cycle Detection
- [ ] Topological Sort
- [ ] Shortest Path
- [ ] Minimum Spanning Tree

## Phase 7 — Greedy

- [ ] Interval Problems
- [ ] Activity / Scheduling Problems
- [ ] Greedy with Sorting
- [ ] Greedy with Heap

## Phase 8 — Dynamic Programming

- [ ] 1D DP
- [ ] 2D DP
- [ ] Knapsack
- [ ] Subsequences
- [ ] Grid DP
- [ ] DP on Trees
- [ ] Advanced DP

## 🎯 Final Targets

By the end of this roadmap, the target is to:

- Solve Easy problems comfortably
- Solve most common Medium patterns independently
- Explain time and space complexity clearly
- Recognize major DSA patterns quickly
- Solve coding interview problems under time pressure
- Revisit and improve problems that initially required help
